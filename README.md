# חוג AI לילדים

אתר עברי שמרכז את מה שלומדים ויוצרים בחוג: שיעורים, כלים ושירים.

| קובץ | מה יש בו |
|---|---|
| `index.html` | דף הבית |
| `lessons/suno.html` | שיעור Suno עם צילומי מסך מסומנים וסרטון הדגמה מונפש |
| `assets/data.js` | רשימת השיעורים, הכלים והשירים |
| `assets/shots.js` | הצילומים, הסימונים וסצנות הסרטון |
| `lessons/img/` | צילומי המסך של Suno |
| `songs/` | מקום אופציונלי לקובצי שירים מקומיים בעתיד |

בדף הבית יש לשונית ״תוצרי השיעור״. בתוכה בוחרים שיר אחד מתוך שבעה, נציג אחד מכל זוג יצירות בחשבון Suno, ורואים נגן אחד בלבד. השירים מתנגנים דרך הנגן הרשמי של Suno; כרגע אין קובצי MP3 במאגר.

## האתר הפתוח

https://shemesh613.github.io/claude-shimshon-site/

קובצי האתר בלבד נמצאים במאגר הציבורי `shemesh613/claude-shimshon-site`. מאגר העבודה הזה נשאר פרטי. לאחר שינוי באתר, יש לעדכן גם את העותק הציבורי.
