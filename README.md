# חוג AI לילדים

אתר עברי שמרכז את מה שלומדים ויוצרים בחוג: שיעורים, כלים ושירים.

| קובץ | מה יש בו |
|---|---|
| `index.html` | דף הבית |
| `lessons/suno.html` | שיעור Suno עם צילומי מסך מסומנים וסרטון הדגמה מונפש |
| `assets/data.js` | רשימת השיעורים, הכלים והשירים |
| `assets/shots.js` | הצילומים, הסימונים וסצנות הסרטון |
| `lessons/img/` | צילומי המסך של Suno |
| `assets/audio/` | שבעה שירים מוקלטים בפורמט MP3 |

בדף הבית יש לשונית ״תוצרי השיעור״. בתוכה בוחרים שיר אחד מתוך שבעה, נציג אחד מכל זוג יצירות בחשבון Suno, ורואים נגן אחד בלבד. השירים הוקלטו מההשמעה במחשב, אחרי ש־Suno הציג אפס הורדות זמינות. ההקלטות נשמרו ב־MP3 סטריאו באיכות 192kbps. אפשר להאזין באתר, להוריד קובץ, או לפתוח את השיר המקורי ב־Suno.
